# User Inquiry & Request Logging Rule (MANDATORY)

## 1. Always Record User Inquiries with Timestamps
- Whenever the user asks a question, gives feedback, or makes a request, **ALWAYS record the text content with its exact timestamp (`YYYY-MM-DD HH:MM:SS`)** into [docs/user_inquiry_log.md](file:///d:/Git_Hub/Test_AI/Test_AI/docs/user_inquiry_log.md).

## 2. Maintain Chronological Order
- Keep the log table well-formatted in markdown with columns:
  - `타임스탬프 (Timestamp)`
  - `구분 (Category)`
  - `질문 및 요청 내용 (User Inquiry / Request)`
  - `비고 / 처리 요약 (Notes / Summary)`
