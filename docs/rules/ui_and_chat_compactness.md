# UI & Chat Formatting Guidelines

1. **Keep Chat & Modal Content Compact**:
   - Never generate excessively tall messages, modals, or prompts that push interactive buttons (e.g., Proceed, Submit, Skip, Restart) off the screen.
   - Summaries, responses, and implementation plans should be concise, structured, and easy to read.
   - If a response is long, format it into short bullet points and ensure any approval/action buttons stay visible and clickable.
