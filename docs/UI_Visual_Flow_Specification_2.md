# 📱 Stone Skipping - UI/UX 화면 구성 및 비주얼 사양서 (Visual Spec)

> **문서 상태**: Approved Draft (로그인, 로비 독바, 맵/모드 선택, 폴더형 도감 팝업, 결과창 분기 확정)  
> **기준 해상도**: 모바일 세로 9:16 (720x1280 Virtual Native)  
> **디자인 테마**: 내추럴 3D 캐주얼 + 반투명 글래스모피즘 (Glassmorphism)

---

## 🖼️ 1. 타이틀 화면 (Title Screen)

### 📋 주요 구성 요소
- **타이틀 로고**: 3D 젤리/스톤 질감의 `Stone Skipping` 입체 로고 & 물보라 파티클.
- **배경 연출**: 호숫가 일출 3D 원경 & 잔잔한 물결 애니메이션.
- 
- **하단 로그인 형태 2종**:
   - **초기형태**
      - 🅺 **카카오 로그인 (`Kakao Login`)**: 브랜드 노란색 버튼 / 카카오 UID, 닉네임, 프로필 동기화.
         - 클릭하면 카카오계정 연동으로 게임 시작.
         - 로그인 버튼을 누르면 '로그인 중입니다' 팝업 표시됨.
         - 로그인 버튼을 누르지 않았다면 게스트로 시작으로 게임 시작.
      - 👤 **게스트로 시작 (`Guest Play`)**: 반투명 글래스 버튼 / 로컬 고유 UUID로 즉시 로비 진입.
   - **자동 로그인 형태**
      - **"Press to Start"**: 카카오UID가 이미 있는상태에서 나오는 UI/ 카카오 로그인,게스트로시작 두개의 버튼이 사라진 위치에 깜박이는 텍스트 형태로 표시. 화면 아무대나 클릭시 카카오 UID로 즉시 로비 진입.
         - 한번 로그인 후에는 카카오 UID로 자동 로그인 형태.
         - 설정에서 로그아웃 하면 다시 초기 형태로 돌아감.

## 🧍 2. 캐릭터 로비 화면 (Lobby & Character Select)

### 📋 주요 구성 요소 & 레이아웃
```
+-------------------------------------------------------------+
| [ 프로필/PebbleMaster ]   [🪙 5,420] [💎 315] [⚡ 10]    [⚙️] | <- 상단 글래스 헤더 바
|-------------------------------------------------------------|
|                                                             |
|                    [ 3D 호숫가 & 나무 발판 ]                  |
|                                                             |
|      <                    🧍‍♂️             ✨🪨✨       >   |
|   [좌 화살표]       [선택된 캐릭터 모델]    [선택된 스톤]  [우 화살표]
|                                                             |
|-------------------------------------------------------------|
|   ┌───────────────────────────────────┐                     |
|   │ 🛒 Shop    📖 Collection    🏆 Rank│       (( GO! ))     | <- 3구 글래스 독 바 & 거대 GO 버튼
|   └───────────────────────────────────┘                     |
+-------------------------------------------------------------+
```

1. **상단 통합 헤더 바**:
   - 아바타 썸네일 + 닉네임 (`PebbleMaster`).
   - 🪙 골드 (`5,420`), 💎 다이아 (`315`), ⚡ 번개 스태미나 (`10`), ⚙️ 설정.
2. **중앙 3D 인터랙션**:
   - 나무 발판 위의 캐릭터 3D 뷰 + 빛나는 돌(Stone) 받침대.
   - 좌우 화살표 (`<`, `>`) 및 화면 스와이프로 캐릭터/스톤 전환.
3. **하단 바 (3단 독 바 & 액션)**:
   - 🛒 **상점 (Shop)**: 돌 가챠, 재화 충전, 스태미나 충전.
   - 📖 **도감 (Collection)**: 다중 폴더 탭형 도감 팝업 호출.
   - 🏆 **랭킹 (Rank)**: 카카오 친구 주간 랭킹, 하트 보내기, 글로벌 순위.
   - 🔘 **`GO!` 버튼**: 3번 맵 & 모드 선택 화면으로 진입.

## 🗺️ 3. 맵 & 모드 선택 화면 (Map & Mode Select)

### 📋 주요 구성 요소
1. **상단 헤더**: 로비 화면과 100% 동일한 통합 글래스 바 유지.
2. **서브 컨트롤**:
   - 좌측: 미니 뒤로가기 아이콘 `[⬅️]`.
   - 중앙: 일체형 라디오 토글 `[ 🔘 Distance Mode (원거리) | ⚪ Cross River / Target (강건너기) ]`.
3. **중앙 맵 대표 카드**:
   - 3D 디오라마 썸네일 (에메랄드 호수 BG_01 등), 난이도 별점, 좌우 넘김 버튼 (`<`, `>`).
4. **하단 전체 코스 곡선 미니맵**:
   - 출발점 `[Start 🚩]` ~ 도착점 `[1500m Finish 🏁]`까지 굽이치는 강줄기 형태 시각화.
5. **하단 액션 버튼**:
   - 에너지 소모 뱃지가 포함된 `[ ⚡-1  GAME START! ]` (인게임 진입).

## 📖 4. 도감 (Collection) 멀티 탭 폴더형 팝업 UI

로비의 하단 독(`[📖 Collection]`)을 누르면 열리는 **글래스모피즘 멀티 탭 폴더창**입니다.

```
┌─────────────────────────────────────────────────────────┐
│                      📖 도 감 (COLLECTION)              │
│  ┌───────────────┬───────────────┬───────────────┐ [X]  │
│  │ 👤 캐릭터 도감 │ 🪨  돌 도감  │ 🐠  수 족 관  │      │
├──┴───────────────┴───────────────┴───────────────┴──────┤
│                                                         │
│  [탭 1: 캐릭터]           [탭 2: 돌]          [탭 3: 수족관]   │
│  - 캐릭터 그리드 카드     - 돌 등급별 그리드  - 3D 원형 수조 뷰 │
│  - 레벨/보너스 스탯       - 반발력/회전력 스펙 - 포획 어종 목록  │
│  - 해금 조건 & 대사       - 궤적 파티클 미리보기- 코인 자동 생산 │
│                                                         │
│ ┌─────────────────────────────────────────────────────┐ │
│ │  선택된 아이템 상세 프리뷰 영역 (3D 턴테이블 회전)    │ │
│ │  "황금 잉어 (길이: 58cm / 포획 수: 3회)"             │ │
│ └─────────────────────────────────────────────────────┘ │
│                                                         │
│          [ 🪙 수족관 방치 코인 수령 ( 350 / 1000 ) ]    │
└─────────────────────────────────────────────────────────┘
```

1. **`[ 👤 캐릭터 도감 ]`**:
   - 그리드 형태의 캐릭터 슬롯 (해금 완료 / 실루엣 잠금).
   - 캐릭터별 패시브 스킬 (예: "완벽 타이밍 판정 범위 +10%", "초기 각도 보정 +5도").
2. **`[ 🪨 돌 도감 ]`**:
   - 등급별(일반 / 레어 / 유니크 / 레전드) 돌 리스트.
   - 물리 특성치 표시 (바운스 탄성 계수, 공기 저항력, 특수 스킬: `불꽃 돌(폭발 가속)` 등).
3. **`[ 🐠 수족관 (Aquarium) ]`**:
   - 인게임 비행 중 스나이프로 맞춘 물고기들이 수영하는 3D 수족관 디오라마.
   - **방치형 보상**: 보유한 물고기들이 시간당 골드 생산 ➜ `[ 🪙 코인 모두 받기 ]` 버튼.

## 🏆 5. 결과 화면 (Result Screen) 및 분기 처리

```
┌─────────────────────────────────────────────────────────┐
│                     🏆 비 행 결 과                      │
│                  최종 거리: 428.5 m                     │
│               [ 🌟 NEW RECORD! 신기록 🌟 ]              │
├─────────────────────────────────────────────────────────┤
│  • 튕김 횟수 (Skips) : 14 회 (콤보 x1.5)                 │
│  • 퍼펙트 타이밍    : 6 회 (+120 점)                    │
│  • 스나이프 물고기  : 황금 잉어 (+150 G)                │
│                                                         │
│  💰 획득 골드 : + 850 G       ⭐ 획득 경험치 : + 120 EXP │
├─────────────────────────────────────────────────────────┤
│   [ 🎬 리플레이 ]      [ 🔁 재도전 (⚡-1) ]    [ 🏠 로비로 ]  │
└─────────────────────────────────────────────────────────┘
```

### 🔄 버튼별 인터랙션 분기
1. **`[ 🎬 리플레이 ]`**:
   - `TopDownReplayManager` 호출 ➜ 카메라 탑뷰 전환 후 이번 판 궤적/바운스 애니메이션 재생.
2. **`[ 🔁 재도전 (⚡-1) ]`**:
   - **스태미나 검사**:
     - ⚡ >= 1: 스태미나 1 차감 ➜ 동일한 세팅으로 인게임 0단계(`Positioning`) 즉시 재시작.
     - ⚡ == 0: **[스태미나 부족 팝업]** 호출 (다이아 구매 or `[📺 광고 보고 번개 2개 충전]`).
3. **`[ 🏠 로비로 ]`**:
   - 획득 재화/도감 데이터 세이브 완료 ➜ 인게임 오브젝트 언로드/비활성화 ➜ **2번 캐릭터 로비 화면 복귀**.
