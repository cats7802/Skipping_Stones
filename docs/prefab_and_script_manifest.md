# 📋 인게임 프리팹 & 스크립트 연동 작업지시서 (Prefab & Entity Manifest)

이 문서는 **게임 내 모든 오브젝트(조약돌, 부스트패드, 장애물, 물고기, 지형 등)의 스크립트 연동 명세**와 **유저님이 직접 3D 리소스로 교체하고자 할 때의 단계별 가이드**를 담고 있습니다.

---

## 🎯 핵심 원칙: 스마트 감지 & 폴백 (User-First & Fallback)

1. **유저 프리팹 최우선 존중**: 유저님이 3D 메쉬나 컴포넌트를 직접 세팅해 두시면 코드는 **임시 메쉬를 생성하지 않고 유저 세팅을 100% 그대로 사용**합니다.
2. **누락 시 무중단 자동 폴백**: 유저님이 아직 3D 모델을 안 만드셨거나 컴포넌트가 빠져있으면, **게임이 정상 플레이되도록 임시 메쉬/컴포넌트를 자동 부착하고 콘솔에 친절한 안내 로그**를 띄웁니다.

---

## 📦 전체 인게임 엔티티 명세 목록

### 1. 🪨 조약돌 (`Stone`)
* **프리팹 경로**: `Assets/Resources/Stone.prefab` (또는 `Assets/3D/prefab/Stone.prefab`)
* **역할**: 유저가 투구하는 메인 조약돌
* **직접 제작 시 가이드**:
  1. `Stone.prefab` 루트에 `Rigidbody` 추가 (Mass: 0.05, FreezeRotationX/Z)
  2. 루트에 `BoxCollider` 추가 (Size: 0.04, 0.03, 0.06, isTrigger: true)
  3. 루트에 `SkippingStone.cs` 부착
  4. (선택) 자식에 3D 조약돌 메쉬 배치
  * *트레일(`TrailRenderer`)이나 링(`RhythmRingIndicator.cs`)은 유저가 안 붙여도 코드가 알아서 안전하게 작동시킵니다.*

---

### 2. 🚀 부스트 패드 (`BoostPad`)
* **프리팹 경로 (제작 시)**: `Assets/Resources/BoostPad.prefab`
* **역할**: 수면에 떠 있는 가속 발판 (돌이 닿으면 전방 속도 x1.35 및 4m 상승 부스트)
* **직접 제작 시 가이드**:
  1. 빛나는 3D 발판/연잎/마법진 모델을 준비
  2. 루트 오브젝트에 `BoostPad.cs` 컴포넌트 부착
  3. (옵션) 인스펙터에서 `boostMultiplier = 1.35f`, `upwardLift = 4.0f` 조절
  * *현재 상태: 유저 프리팹이 없으면 코드가 임시 네온 큐브로 플레이를 지원합니다.*

---

### 3. 🪨 장애물 바위 (`ObstacleRock`)
* **프리팹 경로 (제작 시)**: `Assets/Resources/ObstacleRock.prefab`
* **역할**: 수면에 솟아있는 바위 (돌이 정면 충돌하면 즉시 크래시/침수 정산)
* **직접 제작 시 가이드**:
  1. 바위 3D 메쉬 준비
  2. 루트 오브젝트에 `ObstacleRock.cs` 컴포넌트 부착
  3. 루트에 `MeshCollider` 또는 `BoxCollider` 부착
  * *현재 상태: 유저 프리팹이 없으면 코드가 임시 짙은 회색 바위 큐브로 자동 스폰합니다.*

---

### 4. 🐟 점핑 물고기 (`JumpingFish`)
* **프리팹 경로 (제작 시)**: `Assets/Resources/JumpingFish.prefab`
* **역할**: 돌이 접근하면 수면 위로 펄떡 뛰어오르는 피라미(0~300m), 비단잉어(300~750m), 날치(750m+)
* **직접 제작 시 가이드**:
  1. 물고기 3D 모델 및 애니메이션 준비
  2. 루트 오브젝트에 `JumpingFish.cs` 컴포넌트 부착
  3. 인스펙터에서 `jumpHeight = 2.4f ~ 4.0f` 세팅
  * *현재 상태: 유저 프리팹이 없으면 코드가 은빛 캡슐 메쉬로 점프 연출을 제공합니다.*

---

### 5. 🚩 거리/친구 깃발 (`FriendFlag`)
* **프리팹 경로 (제작 시)**: `Assets/Resources/FriendFlag.prefab`
* **역할**: 100m, 500m, 1,000m 등 주요 거리 및 친구 기록 지점에 꽂혀있는 축하 깃발
* **직접 제작 시 가이드**:
  1. 깃대와 깃발 3D 모델 준비
  2. 루트 오브젝트에 `FriendFlag.cs` 컴포넌트 부착
  * *현재 상태: 유저 프리팹이 없으면 3D 실린더 깃대와 텍스트로 자동 생성됩니다.*

---

### 6. ⭕ 수면 타겟 존 (`FloatingTargetZone`)

* **직접 제작 시 가이드**:
  1. 도넛 형태의 3D 링 모델 준비
  2. 루트 오브젝트에 `FloatingTargetZone.cs` 부착
