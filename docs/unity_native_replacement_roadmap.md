# 📋 [유니티 기본 네이티브 엔진 기능 대체 로드맵]

향후 토큰 충전 시 유니티 공식 표준 기능으로 전환하여 프로젝트 최적화와 유지보수 편의성을 극대화하기 위한 목록입니다.

---

### 1. 🎵 오디오 시스템 (Audio)
* **현재 방식**: `SoundSynthesizer.cs` (C# 코드에서 수학 공식으로 소리 파형을 실시간 합성)
* **유니티 표준 대체**: **`AudioSource` + `AudioMixer` + 실제 음원 에셋(`.wav` / `.mp3`)**
  * **장점**: CPU 연산 낭비 0, 유니티 인스펙터에서 볼륨/피치/사운드 이펙트(리버브 등)를 슬라이더로 손쉽게 튜닝 가능.

---

### 2. 🎥 카메라 추적 및 연출 (Camera)
* **현재 방식**: `DualCameraSetup.cs` (C# `LateUpdate`에서 `Vector3.Lerp`와 오프셋을 수학으로 직접 계산)
* **유니티 표준 대체**: **유니티 공식 `Cinemachine` (시네머신 가상 카메라 시스템)**
  * **장점**: 타깃 추적(Framing Transposer), 회전(Composer), 숄더뷰/비행뷰/탑다운 뷰 간의 부드러운 카메라 블렌딩(전환)을 코드 한 줄 없이 인스펙터 클릭만으로 완벽 제어.

---

### 3. 🌅 환경 및 시간대(낮/노을/밤) 전환 (Environment & Post-Processing)
* **현재 방식**: `LakeEnvironmentManager.cs` (C#에서 안개, 조명색, 셰이더 컬러를 매 프레임 수동 보간)
* **유니티 표준 대체**: **URP `Volume` 및 `Volume Profile` (포스트 프로세싱 볼륨)**
  * **장점**: 낮/노을/밤 프로필을 생성해 두고 볼륨 가중치(Weight 0~1)만 조절하면 톤매핑, 블룸, 안개, 조명이 GPU 셰이더 레벨에서 부드럽게 자동 전환.

---

### 4. 🪨 조약돌 메쉬 생성 (Mesh & Modeling)
* **현재 방식**: `PebbleMeshGenerator.cs` (C#에서 정점 800개를 수학 공식으로 깎아서 메쉬 생성)
* **유니티 표준 대체**: **정식 3D 모델 에셋(`Stone.prefab` / FBX) + `LOD Group`**
  * **장점**: 런타임 정점 계산 낭비 0, 텍스처 매핑과 노멀맵이 완벽하게 적용된 고화질 조약돌 즉시 로딩.

---

### 5. 🌊 궤적 및 강줄기 배치 (Spline / Path)
* **현재 방식**: `PlayerPositionPath.cs` (C# 배열로 좌표를 계산해 수동 보간)
* **유니티 표준 대체**: **유니티 공식 `Splines` 패키지**
  * **장점**: 씬 뷰에서 베지에 곡선으로 강줄기를 마우스로 드래그하여 직관적으로 편집 가능.
