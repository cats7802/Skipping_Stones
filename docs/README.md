# 🌊 Stone Skipping (물수제비 마스터 3D)

> Unity 6 기반 모바일/PC 세로 9:16 최적화 물수제비 타이밍 리듬 액션 게임

---

## 🎮 게임 특징 및 주요 시스템

1. 🪨 **물수제비 물리 & 롤러코스터 카메라**:
   * 완벽한 각도와 파워로 돌을 던져 수면을 튕겨나가는 시원한 손맛
   * 다이내믹 Y-바운스 추적 쿼터뷰 및 전방 장애물 조망 피치 앵글
2. 🎧 **9종 프로시저럴 사운드 (SFX)**:
   * 44.1kHz WAV 파형 합성 에셋 장착 (바람소리, 퐁당 착수음, PERFECT 크리스탈 차임벨, 도로록 스키밍, 코인 챠링 등)
   * 10채널 오디오 풀링 및 $\pm 5\%$ 피치 무작위 변조
3. 📳 **네이티브 햅틱(진동) 시스템**:
   * 일반 바운스(35ms), PERFECT 바운스(55ms 풀파워), 침몰(75ms) 등 타이밍별 세분화된 진동 피드백
4. 🏄 **점진적 '도로록~' 스키밍 피니시**:
   * 5스킵 이상 달성 시 수면을 고속으로 미끄러지며 추가 비거리 보너스 획득
5. 🗺️ **직교(Orthographic) 90도 탑다운 궤적 리플레이**:
   * 침몰 후 전 구간 궤적을 맵에 한눈에 피팅하여 실시간 드로잉 재생 및 파문 애니메이션 제공
6. 🕹️ **2가지 게임 모드 완비**:
   * **[장거리 도전]**: 1,500m 강줄기를 따라 부스트 패드, 물고기 저격, 친구 랭킹 추월 레이스
   * **[타겟 맞추기]**: PP01~PP29 강변 위치 선정 및 수면 플로팅 과녁 타깃 명중 도전

---

## 🚀 빌드 방법

유니티 에디터(Unity 6) 상단 메뉴에서 1클릭으로 빌드 가능:

* 🖥️ **Windows (PC) 빌드**: `Tools ➔ Build ➔ Build Windows Standalone (EXE)`
* 📱 **Android (APK) 빌드**: `Tools ➔ Build ➔ Build Android (APK)`
* 📲 **Android (기기 자동 실행)**: `Tools ➔ Build ➔ Build and Run Android (APK to Device)`
